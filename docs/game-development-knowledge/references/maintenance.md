# 维护、来源与交接

## 知识分层

全局库保存可迁移的诊断方法、接口关系和失败模式；项目约定保存模块路径、构建入口、平台范围及用户偏好；每版自检保存本次日志、截图、数值、哈希和设备结果。全局技能入口只作索引，不默认加载整库。

本库初始经验来自 Tankbattle 原生 PC/Godot 开发，截至 2026-09-12 的 0.4.13：

- 战斗/输入迭代：枪口与弹道、声音、镜头后坐、远程桌面鼠标、手柄断连。
- 0.4.10：怪物波次与生成阻塞、死亡骨骼缓存、隐藏界面刷新。
- 0.4.11–0.4.12：远射与理想机动距离相互影响、发现后追击及搜索记忆。
- 0.4.13：高度场与出生坐标、缓坡误判为障碍、植被 LOD、关卡与菜单扩展。
- Mac 导出与传文件：归档权限/签名、静态验证边界、RDP 映射诊断。

历史可追溯来源为该仓库的 `docs/pc-realistic/DEVELOPMENT_PLAYBOOK.md` 和各版 `SELF_CHECK_*.md`；这些路径仅供已有该仓库时追溯，不是本库的外部运行依赖。本库不要求使用该项目的引擎版本、身份、目录、武器数值或测试通过数。

## 保存一条新经验

只收录已经观察到、会重复使用且能改变下一次决策的内容。用下面的短格式；不要求每次开发生成新文件。

```text
触发条件：玩家在什么条件下看见了什么问题？
证据：哪段实际调用/测量复现了问题？
机制：问题为什么发生？哪些仍是假设？
有效改动：最小修复改变了哪一项关系？
验证：真实路径如何通过，边界测试是什么？
适用范围：哪个引擎/版本/资产/设备下成立？
不应推广：哪些数值、机器设置或授权仅限此项目？
```

同主题优先修正已有条目，删除被证伪的结论，避免把一次绕过故障的做法追加成全局强制步骤。涉及版本变化的 API 保留症状和核验方法，不长期复制脆弱接口代码。

库中没有完整模型、录音或外部可执行文件，只保存工作方法与来源说明。新增脚本只有在确实重复使用且已运行验证时才加入；不为文档搭建空架构或模板工程。

## 让下次任务少读、少问、少重跑

交接留下一段状态即可：目标平台/引擎、当前分支、相关文件与函数、已完成修改、对应验证、仍未确定的根因、下一步、产物路径，以及已授权范围。注明有无未提交的他人修改。

不要复制完整聊天和所有日志；保留可定位的证据路径。把性能假设、已证实根因与工作计划分开，避免后续 GPT 把前一轮猜测当事实。

此目录可以作为普通 Markdown 知识库提供给其他 GPT 工具。全局技能安装只作用于安装它的本机 Codex；不会自动传播到别的电脑、账号或 ChatGPT 对话。若维护的是仓库中的可移植副本，修改后校验并同步全局副本；有不同本地修改时先检查差异，不能整目录覆盖已有个人内容。
