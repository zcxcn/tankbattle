# Windows PC 0.4.11 — 敌车远距离交战

## 修改

- 普通主炮、重装、巡护、抢修和侦察车索敌范围从 40–50m 提高到 130–160m。
  机枪车为 120m，火箭车 190m，歼击车 200m，榴弹车 210m，远射车和 Boss 220m。
- 机动时的理想距离按角色扩大到 50–125m。装填接近完成且有可见目标时，
  敌车会先停车稳定瞄准、射击，再在装填期间调整位置。
  之前它们持续靠近 23–52m 的理想距离，无法通过“车体稳定才能射击”的条件。
- Boss 火箭齐射使用可视射程，继续保留原有锁定位置、预警时间和恢复窗口。
- 敌方侧置火箭筒增加有限水平会聚，让真实筒口方向对准远方目标。
  玩家火箭筒未改动；炮弹仍沿真实枪管/筒口发射，经过实际弹道和扫掠碰撞。
- 原有建筑遮挡、视野角、瞄准时间、装填间隔、伤害和玩家武器参数保留。

## 验证

新增 `tests/enemy_range_test.tscn` 使用实际坦克 AI、炮弹与物理碰撞，
不强制调用 `try_fire()`。在地图外的平坦试射区，从 100/120/160/190m 间距开始，
检查普通主炮、重炮、远射主炮、火箭、机枪及 Boss 主炮实际发射并伤到玩家；
首发发生时仍显著远于各车理想机动距离。装填期间敌车可以移动，不把初始距离
误报为所有命中时刻的精确距离。

同时验证远方建筑阻挡观察与开火、遮挡取消已准备的射击、视野仍有上限，
以及 Boss 可从远距离预警齐射。固定随机种子控制发射散布，保留原来的瞄准误差。

增量回归日志放在 `work/pc0411-*.log`：远射 16 项、战斗节奏 50 项、
炮管俯仰 16 项、弹道 23 项、载具/武器与感知 41 项，共 146 项。
战斗节奏测试沿用构建脚本的实时执行方式；固定 FPS 快进会令其模拟计时器
在音频退出阶段先到超时，不能把这种退出失败视为通过。

本轮为敌方坦克逻辑增量修复，不改模型、画质、Android 或网页，也不重新导出 Mac。
发布时复用以上相关验证，重导出仍执行 EXE 启动、版本、清单、哈希和 ZIP 检查。
