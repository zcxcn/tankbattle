# 网页部署与地图升级验收 · 2026-09-12

本次范围为网页版，Android 冻结基线与 Godot PC 源码未修改。

## 已验证

- 部署菜单：1280×800、390×844、320×568、844×390、568×320 浏览器视口；没有整页水平或垂直滚动，开战按钮固定可见。最矮横屏的玩法面板仅有少量内部滚动。
- 车库的底盘、装备、成长、升级切换；战地档案与敌军识别入口；战役按六章翻页和章节锁定。
- 雨林与城区实际进入；横竖屏移动、开火、释放输入、布雷、脉冲排雷、镜头切换、暂停、返回与取消加载后再次进入；浏览器没有捕获运行错误。
- 64 项战斗逻辑检查，包括六张地图与八种任务的 48 种组合、敌军分布、出生避让、任务可达、护送通道、过桥、建筑毁坏后通行和快速作战存档隔离。
- 六地图几何检查：山体与碰撞边界一致、表面法线正确；建筑损坏和废墟切换没有增加网格或材质；异步场景创建实际让出执行时间，并支持取消。
- 加载检查：素材完成量、首屏着色器和阴影、首帧提交、资源错误、超时、后台恢复、加载中旋转，以及效果池尚未创建时取消。
- 原有 41 项 3D 集成检查以及触控、HUD、表面材质、音乐、战术播报和战斗音效检查通过。最后的森林排布和水面细化又通过地图及战斗专项检查。
- TypeScript 检查和 GitHub Pages 构建/资源验证通过；57 个 Android 冻结文件校验一致。

## 性能记录与限制

本地浏览器抽样记录中，雨林首屏准备约 3.4 秒，城区约 7.1 秒。计时从预载后的渲染器创建开始，不含首次页面下载；城区样本测试时同机也有自动检查运行，不能视为严格性能基准。新版使用分批场景创建和首屏材质/光照检查，取消对禁用废墟、远处物体全部着色器的等待，声音资源在可以操作后继续准备。没有新增模型或贴图下载。

浏览器尺寸模拟不等于实体手机验收；本次没有实体手机结果。全仓 `npm run lint` 仍存在原有共享 UI、React 编译检查及 Android 冻结副本等报错；本轮新增菜单、进度条和场景方法引入的检查问题已修复，未修改冻结副本来消除历史报错。
