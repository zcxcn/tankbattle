# 战斗视野与野外巡逻验收 · 2026-09-12

本轮仅修改网页版；城市保留，地图选项收敛为城市与山林荒野。Android 冻结基线 57 个文件校验通过，PC Godot 未修改。

## 行为与画面

- 战场画布铺满视口，顶部背景透明。目标置于左上角，武器栏默认收起，升级/补给/英文字幕合并成左下角小字。移除中间升级框、顶部状态条、Boss 齐射提示与反复齐射播报。
- 手机武器栏竖屏为右侧两列，横屏为右侧四列；选择后自动收起。雷达与武器面板互斥，常用触屏按钮至少 44×44 CSS 像素。
- 山林荒野没有房屋、货箱或铁路。8 座山丘使用连续圆润表面和椭圆碰撞；3 片浅水可涉过，水底可见、岸线透明渐变，涉水速度为 72%。
- 敌车在部署点附近巡逻，接近且无遮挡才攻击；超过巡逻限制后返回。Boss 蓄力锁定原目标，目标远离或被掩体挡住后取消攻击。普通敌军布雷尝试成功率 18%，Boss 为 25%，每次尝试间隔 35–55 秒。
- 加农炮固定专业录音与音高，录音延迟解码不会中途改变本局炮声音色；特殊弹药拾取不再自动换武器。其余专业录音保留。
- 掉落物使用打开的炮弹箱、维修工具箱、超频电容和装甲能源盒四类模型，单类最多 5 个主体批次，几何缓冲共享，最多复用 20 个可见补给槽位。

## 验证

- 70 项战斗逻辑检查通过，涵盖两张地图与八种玩法的路线可达、涉水、椭圆碰撞、附近巡逻、视线与距离约束、Boss 蓄力取消、隔墙爆炸、低频布雷和弹药库存。
- 补充模拟 48 局（两图 × 八种玩法 × 三个种子），每局在出生点静置 40 秒，玩家掉血为 0。敌军只向附近可见的前置信标开火。
- 两地图几何与破坏检查通过：山脚贴地、法线朝上、碰撞轮廓匹配；水面浅而可涉，城区楼房损坏/废墟切换不增加网格。
- 41 项 3D 集成检查通过，包含四类补给几何不同、共享缓冲、反复切换类型不增长网格/材质/几何数量。另通过加载进度与取消、HUD、双指触控、素材、音乐和全部声音专项检查。
- 12 项炮声检查包括读取真实 WAV 的 PCM 数据，在敌人夹杂射击、部分下载与延迟解码后仍保持同一录音/合成缓冲、音高和低频处理。28 项战术播报检查通过，21 个英文语音与 19 个战斗录音素材校验通过。
- 本地浏览器检查 1280×800 桌面、844×390 横屏与 390×844 竖屏，实际操作移动、右杆炮击、切换加农炮、布雷、脉冲排雷、雷达、暂停与旋转恢复。竖屏画布高度覆盖全部 844 CSS 像素，顶部计算背景为透明。控制区之外视野畅通，未发现横向滚动。本轮未使用实体手机或外接扬声器验收。
- 网页 TypeScript 严格检查通过，Pages 打包和路径/静态资源校验通过。整仓 lint 仍有共享 UI、旧 Hook 与冻结 Android 文件的已有规则错误，未宣称整仓 lint 通过。
