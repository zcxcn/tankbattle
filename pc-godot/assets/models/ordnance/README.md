# Iron Embers original ordnance

These four original GLB meshes are generated by `pc-godot/tools/build_ordnance.py`.
They contain closed metallic projectile bodies, curved ogive profiles, copper
driving bands, a separate HE fuze, and a rocket motor with four closed stabilizer
fins and an inset exhaust nozzle. Flying rounds do not include cartridge cases.

| Asset | Triangles | Physical overall length |
| --- | ---: | ---: |
| `ap_shell.glb` | 1,280 | 0.66 m |
| `he_shell.glb` | 1,200 | 0.58 m |
| `machine_gun_bullet.glb` | 528 | 0.055 m |
| `rocket.glb` | 1,488 | 1.11 m |

Forward is -Z; coordinates are metres. Runtime instances share imported meshes
and materials. The gallery magnifies specimens for inspection; actual flight
uses the authored metre scale. The projectile geometry is representative game
art, not a manufacturer-certified replica or an engineering specification.
