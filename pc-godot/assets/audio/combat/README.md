# PC combat recording credits

These clips are copied unchanged from the previously licensed web combat pack.
The Godot PC version plays them locally. Android and web assets are unchanged.
`provenance.json` preserves original source URLs, source SHA-256, source slices,
editing descriptions, and checksums for every included file.
